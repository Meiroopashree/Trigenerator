Title: Space Mission Crew Management System

Description: 
You need to create the Missions table in the appdb database with the necessary columns for mission records. Then, develop a console-based C# application using ADO.NET to perform Create, Read, Update, and Delete (CRUD) operations on the Missions table in a SQL Server database. The application should enable users to add new mission records, display mission records (with a limit), update mission records, and delete mission records by mission name. The project should be implemented exclusively using a disconnected architecture with SqlDataAdapter, DataSet, and DataTable. All classes, properties, and methods should be made public.

Classes and Properties
Astronaut Class (Models/Astronaut.cs):

The Astronaut class represents an astronaut record with the following public properties:

AstronautID (int): Unique identifier for each astronaut record. Auto-incremented in the database.
Name (string): Name of the astronaut.
Specialization (string): Specialization of the astronaut.
ExperienceYears (int): Years of experience in space missions.
MissionCount (int): Number of space missions the astronaut has participated in.
TotalMissionHours (decimal): Total hours spent in space across all missions (MissionCount * 200).

Access Modifier: public

Methods:

Define the following methods inside the Program class, located in the Program.cs file.



1. AddAstronautRecord(Astronaut astronaut)

Inserts a new astronaut record into the Astronauts table. The method validates the input for ExperienceYears and MissionCount before adding the record to the DataTable. If the validation fails, an error message is displayed, and the operation is terminated.
Parameters: astronaut: An object of the Astronaut class containing the details of the astronaut to be added.
Access Modifier: public
Declaration Modifier: static
Return Type: void
Console Messages:
On success: 
Astronaut record added successfully.
If ExperienceYears or MissionCount is less than 0:
Experience years and mission count must be non-negative values.


2. DisplayLimitedAstronautRecords(int limit)
Fetches a limited number of astronaut records from the Astronauts table and displays them. 
Parameters: limit: The maximum number of astronaut records to display.
Access Modifier: public
Declaration Modifier: static
Return Type: void
Console Messages: 
If records are found: 
Name: {row["Name"]}, Specialization: {row["Specialization"]}, Experience: {row["ExperienceYears"]} years, Missions: {row["MissionCount"]}, Total Hours: {row["TotalMissionHours"]}
If no records are found: 
No astronaut records found.


3. UpdateAstronautRecord(string name, Astronaut updatedAstronaut)

Updates the details of an existing astronaut record in the Astronauts table. The method validates the input for ExperienceYears and MissionCount before updating the record. If the validation fails, an error message is displayed, and the operation is terminated.
Parameters: 
name: The name of the astronaut to be updated.
updatedAstronautt: An object of the Astronaut class containing the updated details.
Access Modifier: public
Declaration Modifier: static
Return Type: void
Console Messages:
If the astronaut is successfully updated:
Astronaut record updated successfully.
If no record is found:
No matching astronaut record found.
If ExperienceYears or MissionCount is less than 0:
Experience years and mission count must be non-negative values.


4. DeleteAstronautRecord(string name)

Deletes a astronaut record from the Astronauts table. 
Parameters:
name: The name of the astronaut to be deleted.
Access Modifier: public
Declaration Modifier: static
Return Type: void
Console Messages:
If the astronaut is successfully deleted:
Astronaut record deleted successfully.
If no record is found:
No matching astronaut record found.


Main Menu:

The main menu serves as the user interface for interacting with the system. It provides the following options:



Space Mission Crew Management Menu

1. Add Astronaut Record: Prompts for the astronaut details. After gathering the details, it calls the AddAstronautRecord(Astronaut astronaut) method to add the new astronaut record to the system.

2. Display Limited Astronaut Records: Displays limited astronaut records by calling the DisplayLimitedAstronautRecords(int limit) method.

3. Update Astronaut Record: Prompts for the astronaut name to identify the record to update. After gathering the input, it calls the UpdateAstronautRecord(string name, Astronaut updatedAstronaut) method to modify the relevant astronaut details if the record exists. It also validates fields like ExperienceYears and MissionCount to ensure they are non-negative before updating.

4. Delete Astronaut Record: Prompts for the Name of the astronaut to be deleted. After gathering the input, it calls the DeleteAstronautRecord(string name) method to remove all astronaut records of the specified name from the system if they exist.

5. Exit: Exits the application with the message "Exiting the application..."

Invalid choice - Displays "Invalid choice."
